一、岗位职责
    1、基于 Python 技术栈负责健康食品电商后台服务、会员数据管理系统、库存与订单处理模块的开发、迭代与维护；
    2、设计并实现 RESTful API 接口，支撑前端业务需求，保障接口稳定性与响应效率；
    3、参与数据库（MySQL/PostgreSQL）设计、优化，处理用户数据、订单流水等核心业务数据，解决数据查询性能问题；
    4、利用 Python 数据处理库（Pandas/NumPy）实现数据同步、报表生成、业务数据统计分析功能；
    5、协同前端、产品、测试团队完成需求评审、技术方案设计，保障项目按时交付；
    6、编写技术文档（接口文档、数据库设计文档），参与代码评审与团队技术沉淀。
